# PVZRHTools 基本特性功能

本文档介绍两个页签：

- **常用功能**（左侧栏第 1 项）—— 最常用的开关
- **全局特性修改**（左侧栏第 3 项）—— 分为 8 个分组

礼盒修改与数值修改另见 [04-礼盒与数值修改](04-礼盒与数值修改.md)。

---

# 一、常用功能

页面顶部是「基本特性」分组，下面依次是「关卡特性附加」「数值修改」「布阵」「游戏状态调整」等常用区块的快捷入口。

| 功能 | 说明 |
|------|------|
| 开发者模式 | 启用游戏内置的开发者调试功能 |
| 手套无CD | 手套使用后立即可用，无需等待冷却 |
| 锤子无CD | 锤子使用后立即可用，无需等待冷却 |
| 植物卡槽无CD | 所有植物卡片无冷却时间 |
| 自由种植 | 可在任意位置种植植物，无需满足种植条件 |
| 解锁全部融合配方 | 解锁所有植物融合配方 |
| 手推车无CD | 小推车无冷却 |
| 取消游戏失败 | 游戏失败时按下：关闭失败界面、秒杀场上僵尸并继续游玩 |
| 深渊作弊 | 深渊模式的作弊功能 |
| 加载自定义植物数值表 | 加载自定义的植物属性配置（由于代码限制，无法保证所有条目均能生效） |

---

# 二、全局特性修改

含 **8 个分组**：基本特性、礼盒修改、数值修改、关卡特性附加、场地特性、植物特性、**僵尸特性**、其他特性。

> 其中「基本特性」与「关卡特性附加」两组在**常用功能**页上也会出现
> （常用功能页把最常用的几组拼在一起，方便一处开关）。
> 礼盒修改与数值修改两组见 [04-礼盒与数值修改](04-礼盒与数值修改.md)。

| 功能 | 说明 |
|------|------|

| 手套无CD | 手套使用后立即可用 |
| 锤子无CD | 锤子使用后立即可用 |
| 植物卡槽无CD | 所有植物卡片无冷却时间 |

### CD 与速度

| 功能 | 说明 |
|------|------|
| 锁定手套CD | 把手套冷却锁定为指定数值 |

## 2.2 关卡特性附加

给关卡叠加特殊规则，**需要在进入关卡前开启**。

| 功能 | 说明 |
|------|------|
| 排山倒海 | 一种种一列（纵列种植） |
| 种子雨 | 启用种子雨关卡模式 |
| 解除融合限制 | 解除植物融合限制（**即时生效**） |
| 胆小菇之梦 | 启用胆小菇之梦关卡模式 |

> 该分组也显示在「常用功能」页上。

## 2.3 场地特性

| 功能 | 说明 |
|------|------|
| 不生成冰道 | 冰车僵尸不会生成冰道 |
| 取消冰冻特效 | 禁用全屏冰冻特效，但保留冻结僵尸和雪原植物充能效果 |
| 取消红卡种植限制 | 允许种植全部红卡植物 |
| 砸罐子修复 | 修复砸罐子关卡问题：重叠罐子只砸一个、小丑/巨人/AOE 不破坏罐子 |
| 阳光无上限 | 取消 50000 阳光存储上限限制 |
| 物品不消失 | 掉落的卡片、肥料、水桶等物品不会消失 |
| 卡槽无初始CD | 游戏开始时卡槽没有初始冷却时间 |
| 小丑盒子不爆 | 小丑僵尸的盒子不会爆炸 |
| 大蒜天 | 每隔一段时间自动对所有僵尸施加大蒜效果 |

## 2.5 僵尸特性

### 血量与速度

| 功能 | 说明 |
|------|------|
| 僵尸限伤 | 僵尸每次受到的伤害**不超过**右侧设定值 |
| 僵尸速度倍率 | 全场僵尸移动速度乘以右侧倍率（0.1–10 倍） |
| 僵尸攻击力倍率 | 全场僵尸攻击伤害乘以右侧倍率（0.1–100 倍） |
| 僵尸血量倍率 | 勾选后按倍率缩放【**新生成**】僵尸的血量（含一/二类甲），倍率 0.1~10 |
| 全场血量×N | **一次性动作**：把【场上已有】的全部僵尸血量按倍率缩放并刷新血条 |

> 「僵尸血量倍率」作用于**之后生成**的僵尸；「全场血量×N」是立刻作用于**已有**僵尸。

### 复活

| 功能 | 说明 |
|------|------|
| 阴魂不散复活概率 | 自定义「阴魂不散」的满血复活概率（**需该词条已生效**，每只僵尸只能复活一次），0–100%，默认 1/3 |
| 独立概率复活（无需词条） | 僵尸死亡时按概率满血复活，**不依赖词条**；同一只僵尸**可多次复活**，0–100% |

### 其他

| 功能 | 说明 |
|------|------|
| 僵尸概率反弹子弹 | 僵尸受到子弹攻击时有一定概率将子弹反弹回去，概率 0–100% |
| 僵尸状态并存 | 僵尸的红温（火焰）状态可与寒冰、蒜毒状态同时存在，不再互斥 |

### 僵尸免疫效果

「僵尸免疫效果」是一组**逐项勾选**的免疫开关，勾上哪项就免疫哪种负面效果：

| 功能 | 说明 |
|------|------|
| 冻结 | 免疫冻结 |
| 减速 | 免疫减速 |
| 黄油定身 | 免疫黄油定身 |
| 蒜毒 | 免疫蒜毒 |
| 红温 | 免疫红温 |
| 余烬 | 免疫余烬 |
| 击退 | 免疫击退 |
| 魅惑 | 免疫魅惑 |
| 吞噬 | 免疫吞噬 |

共 9 项，可任意组合。

## 注意事项

- 标有「需在进入关卡前开启」的分组（关卡特性附加），局内再开不生效
- 部分功能可能与其他功能存在兼容冲突，请逐个开启排查
- 「植物攻击无间隔」「窝红温了」等高频功能可能影响游戏性能

# PVZRHTools 礼盒与数值修改

本文档介绍「全局特性修改」页里的两个分组：

- **礼盒修改**
- **数值修改**

（这两个分组在**常用功能**页上也能看到，设置是同一份。）

---

## 一、礼盒修改

| 功能 | 说明 |
|------|------|
| 超级礼盒 | 礼盒开出更强力的植物 |
| 盒子僵尸概率出究极僵尸 | 盒子僵尸有概率生成究极僵尸 |
| 礼盒快速打开 | 礼盒立即打开，无需等待动画 |
| 锁定礼盒植物 | 锁定礼盒开出的植物类型为指定植物 |

### 锁定礼盒植物

1. 勾选「锁定礼盒植物」
2. 在下拉框中选择想要的植物
3. 之后所有礼盒都会开出该植物

---

## 二、数值修改

> 页面提示原文：**设为 -1 以还原数值**

### 生命值修改

| 功能 | 说明 |
|------|------|
| 僵尸初始血量修改： | 修改指定僵尸的初始生命值 |
| 一类防具血量修改： | 修改僵尸一类防具（路障、铁桶等）的血量 |
| 二类防具血量修改： | 修改僵尸二类防具（报纸、门板等）的血量 |

下方三个只读项显示当前锁定值：

| 项 | 说明 |
|------|------|
| 一类防具血量 | 当前一类防具血量设定值 |
| 二类防具血量 | 当前二类防具血量设定值 |
| 僵尸血量 | 当前僵尸血量设定值 |

### 子弹修改

| 功能 | 说明 |
|------|------|
| 子弹伤害值修改： | 修改指定子弹类型的伤害值 |
| 锁定全部子弹类型： | 将所有植物发射的子弹锁定为指定类型 |

> **关于子弹名称**
> 原文说明：绝大多数子弹没有广泛使用且一目了然的中文名，
> 故只保留蓝飘飘在源代码中的**英文命名**，若看不懂名称点开试一下即可。

---

## 三、使用示例

### 修改僵尸血量

1. 在「僵尸初始血量修改」下拉框中选择目标僵尸
2. 在数值框中输入新的血量值
3. 点「修改」

### 还原为默认

把数值改为 **-1** 即可还原。

---

## 注意事项

- **「设为 -1 还原」**是这一页的通用规则，忘了这条会以为功能坏了
- **锁定子弹类型可能引发各种奇怪的 bug，仅供娱乐，不会做针对性修复**（原文警告）
- 数值修改**不受「关闭时保存现有设置」影响** —— 该开关明确排除数值修改与游戏内词条修改
- 部分数值受游戏硬编码限制，改了可能不生效

# PVZRHTools 旅行词条与快捷键

本文档介绍三个页签：

- **旅行词条修改**（左侧栏第 5 项）—— 词条设置
- **全局按键绑定**（左侧栏第 6 项）—— 全局快捷键
- **游戏内按键绑定**（左侧栏第 7 项）—— 仅游戏内生效的单键快捷键

以及 **杂项**（第 8 项，含设置 / 外观 / 关于）。

---

## 一、旅行词条修改

页面顶部有**搜索框**与「搜索」按钮：按关键词过滤本页词条（也可直接在输入框按回车）。

页面共 **5 个分组**，每组都带「全选」「全不选」两个快捷按钮。

### 分组一览

| 分组 | 生效方式 | 说明 |
|------|----------|------|
| 初始植物词条设置 | 开局自动添加 | 每局游戏开始时 / 生存模式第 1 轮作为初始词条自动添加，**局内修改无效** |
| 植物词条实时修改 | 实时同步 | 与游戏实时同步，可任意增删词条，但**仅对本局有效** |
| 初始僵尸词条设置 | 开局自动添加 | 同「初始植物词条」，对僵尸生效 |
| 僵尸词条实时修改 | 实时同步 | 同「植物词条实时修改」，对僵尸生效 |
| 投资词条实时修改 | 实时同步 | 投资类词条，实时生效，仅本局有效 |

> 页面上「投资词条实时修改」排在「僵尸词条实时修改」**之前**，这是界面的实际排列顺序。

### 使用要点

- **初始类**分组：需在**进入关卡前**设置好，进了关卡再改不生效
- **实时类**分组：游戏中随时可改，改完立即生效，只影响本局
- 词条条目由游戏数据（`InitData.json`）动态生成，数量很多
- 用搜索框能快速定位 —— 词条多时强烈建议先搜再勾
- 「全选」/「全不选」作用于**当前分组内**的全部词条，点之前想清楚

> 还有两个与词条有关的页签：「词条专区」和「旗帜波词条」，
> 见 [09-词条专区与旗帜波词条](09-词条专区与旗帜波词条.md)。

## 二、全局按键绑定

### 设置方法（原文）

> - 请不要设置单键，部分功能需提前填好数据，游戏运行时其他软件中下列键位均失效，可能导致冲突
> - 设置方法：调节为**英文输入法**，将鼠标指针放在对应条目的框上，**先设置 Ctrl/Shift/Alt，再设置要组合的键位**
> - 按键绑定控件来自于 FastHotKeyForWPF，使用时**务必切换成英文输入法**！

### 可绑定功能（共 39 项）

| 分类 | 功能 |
|------|------|
| 基本特性 | 手套无CD、锤子无CD、植物卡槽无CD、自由种植、解锁全部融合配方 |
| 速度与关卡 | 游戏加速、游戏减速、胆小菇之梦、排山倒海 |
| 植物 | 植物攻击无间隔、植物无敌 |
| 生成 | 生成植物、生成僵尸、生成物品、生成究极陨星、斗蛐蛐快速布阵 |
| 阵型 | 植物布阵、僵尸布阵、读取场上植物代码、读取场上僵尸代码 |
| 僵尸海 | 极限僵尸海 |
| 资源 | 修改阳光、锁定阳光、修改钱数、锁定钱数 |
| 清除 | 清空全部植物、秒杀全部僵尸、清除所有冰道、魅惑所有僵尸、清除所有坑洞 |
| 波次 | 生成下一波僵尸、暂停出怪 |
| 其他 | 僵尸进家不死、取消游戏失败、启动所有小推车、生成小推车、修改关卡名称、显示字幕 |
| 窗口 | 显示悬浮窗、显示修改窗口 |

每一行右侧还有「清空」按钮，可清除该条绑定。

### 注意事项

- **强烈建议用组合键**，不要用单键
- 部分功能需要**提前填好数据**（例如「生成植物」要先在页面里选好植物类型）
- 游戏运行时，这些键位在其它软件中会失效，可能与其他软件冲突
- 必须切换为英文输入法才能正常录入

## 三、游戏内按键绑定

> 页面说明原文：**仅支持单键，按键仅在游戏内生效。**

与「全局按键绑定」的区别：

| | 全局按键绑定 | 游戏内按键绑定 |
|---|---|---|
| 键位形式 | 组合键（Ctrl/Shift/Alt + 键） | **仅单键** |
| 生效范围 | 全局（可能影响其它软件） | **仅游戏内** |
| 条目数 | 39 | 9 |

### 可绑定项（共 9 项）

| 功能 | 说明 |
|------|------|
| 高级时停 TimeStop | 高级时间暂停 |
| 卡槽栏置顶 TopMostCardBank | 切换卡槽栏置顶 |
| 显示CD信息 ShowCDInfo | 显示波数、刷新 CD 等游戏信息 |
| 图鉴种植：植物 AlmanacCreatePlant | 在图鉴中点击植物后用该键创建 |
| 图鉴种植：僵尸 AlmanacCreateZombie | 在图鉴中点击僵尸后用该键创建 |
| 图鉴种植：僵尸是否魅惑 AlmanacZombieMindCtrl | 切换图鉴创建的僵尸是否为魅惑状态 |
| 图鉴种植：植物罐子 AlmanacCreatePlantVase | 创建植物罐子 |
| 图鉴种植：僵尸罐子 AlmanacCreateZombieVase | 创建僵尸罐子 |
| 随机卡槽 RandomCard | 切换随机卡槽功能 |

> 括号里的英文是功能内部标识，便于与游戏内名称对照。

### 图鉴快捷创建功能

1. 打开游戏内图鉴
2. 点击想要的植物 / 僵尸
3. 按下对应快捷键，即可在鼠标位置创建

支持的图鉴类型：植物图鉴、僵尸图鉴、新版图鉴 UI、植物图鉴控制器。

## 四、杂项

### 通用设置

| 选项 | 说明 |
|------|------|
| 关闭时保存现有设置 | 关闭修改器时保存当前设置（**数值修改与游戏内词条修改除外**） |
| 悬浮窗 | 双击悬浮窗使修改窗口前置，推荐全屏时使用 |
| 启用修改器动画效果 | 启用或禁用修改器窗口的动画效果（包括启动、激活、关闭等动画） |

### 外观与窗口

| 选项 | 说明 |
|------|------|
| 切换到深色 / 浅色模式 | 点击切换深浅色模式（使用 Infinite-75 经典配色方案） |
| 复原修改器窗口默认大小 | 窗口被拉得过大/过小后一键还原 |

> 「切换到深色模式」与「切换到浅色模式」是**同一个按钮的两种文案**，点击即在两态之间切换。

## 附：关于「卡槽替换」

早期版本有一个独立的「卡槽替换」页签，**在当前版本中已从界面移除**（页签不再显示）。

移除原因（原文）：

> 此修改由于无法修复的 bug 过多，暂时将就着玩吧，仅供娱乐，重启游戏可能会解决问题

替代方案：用「随机卡槽」功能（见 [02-基本特性功能](02-基本特性功能.md)）改变卡槽植物。

# PVZRHTools 诸神进化

页签名：**诸神进化**。专用于「**诸神：进化**」模式的调整页。

> 页面说明原文：专用于「诸神：进化」模式。进入该模式后调整生效；数值类选项需勾选启用后才会覆盖游戏默认值。

## 使用要点

- **只对「诸神：进化」模式生效**，其它模式没有效果
- 数值类选项都要**先勾选左边的小方框**（启用），右边输入框才会生效
  —— 不勾选 = 沿用游戏默认值
- 改完之后点页面底部的「**立即应用到局内**」让改动生效
- 点错的可以「恢复默认」一键还原

---

## 一、刷新与升级

| 选项 | 说明 |
|------|------|
| 词条无限刷新 | 刷新词条不消耗次数 |
| 升级品质无消耗 | 升级词条品质不消耗资源 |
| 锁定刷新次数 | 把刷新次数固定为右侧填写的数值 |

> 「锁定刷新次数」需先勾选启用，再填数值。

## 二、局内属性

| 选项 | 说明 |
|------|------|
| 幸运值 | 影响高品阶词条与质变的出现权重（上限 9999，支持两位小数） |
| 难度 | 局内难度数值（0–99） |
| 最大植物数 | 局内可拥有的植物数量上限（1–999） |
| 词条选项数 | 每次刷新给出的词条选项个数（1–10） |
| 升级品质次数 | 可升级品质的次数上限 |
| 强制超级升级 | 强制走超级升级 |
| 必出超质变词条 | 每次刷新**必定**出现质变 / 超质变选项（含 AdvBuff 质变与植物质变词条） |
| 植物坚不可摧 | 植物不会被碾压 / 破坏 |
| 伤害倍率 | 伤害倍率（0.1–100，支持两位小数） |

> 除「强制超级升级」「必出超质变词条」「植物坚不可摧」三个是纯勾选项外，
> 其余数值项都需要**先勾选启用**再填数值。

## 三、词条品质权重

勾选「**自定义品质权重**」后，下面四个数值框才会生效：

| 品质 | 说明 |
|------|------|
| 普通 | 普通强化词条的权重 |
| 白银 | 白银强化词条的权重 |
| 黄金 | 黄金强化词条的权重 |
| 钻石 | 钻石强化词条的权重 |

> 权重影响普通 / 白银 / 黄金 / 钻石强化词条；
> **幸运值会同步放大高品阶权重与质变出现权重**。
> 勾选「必出超质变词条」后，每次刷新必定出现质变 / 超质变选项（含 AdvBuff 质变与植物质变词条）。

## 四、概率提升 · 一键解锁 · 诸神币

### 概率提升（勾选项）

这些开关用来**大幅提高特定类别词条的出现概率**：

| 选项 | 说明 |
|------|------|
| 试炼概率提升 | 大幅提升试炼类词条出现概率（优先级低于棱彩，不支持部分词条） |
| 战术概率提升 | 大幅提升战术类词条出现概率（优先级低于棱彩） |
| 隐藏难度 | 解锁被隐藏的难度选项（与游戏内 `shoothard` 命令效果相同） |
| 专家邀请概率提升 | 大幅提升专家邀请类词条出现概率（开启后注册「专家邀请」选项，供自选专家植物） |
| 超进化概率提升 | 大幅提升超进化（星辉）类词条出现概率（其出现权重按 1 计算） |
| 质变概率提升 | 接管词条注册流程，使质变词条必定进入选项池（已有质变记录的植物除外） |
| 棱彩概率提升 | 品质判定必定产出棱彩词条（与随机词条同开时**棱彩优先**） |
| 随机概率提升 | 品质判定必定产出随机品质词条 |

### 一键解锁

| 按钮 | 说明 |
|------|------|
| 一键解锁诸神进化 | **一次性动作**：解锁诸神进化的全部植物、路线与战术上限 |

### 诸神币

| 项 | 说明 |
|------|------|
| 诸神币数量 | 要写入存档的诸神币数量 |
| 应用诸神币 | 把上方数值写入诸神进化存档（**写即持久**） |

## 五、底部操作

| 按钮 | 说明 |
|------|------|
| 立即应用到局内 | 把本页当前设置应用到正在进行的局内 |
| 恢复默认 | 把所有选项恢复为默认值 |

---

## 注意事项

- 本页所有功能都**需要连接游戏**才有效果
- 「一键解锁诸神进化」「应用诸神币」是**一次性动作**，点一次执行一次，不是开关
- 诸神币是**写存档**操作（持久保存），请谨慎填写数值
- 部分概率提升类选项**不支持部分词条**（如试炼、战术类），这是游戏侧限制

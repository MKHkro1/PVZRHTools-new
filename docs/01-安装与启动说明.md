## 安装步骤

1. 下载修改器压缩包并解压
2. 将解压后的**全部内容**复制到游戏根目录（与游戏 exe 同一层），遇到覆盖提示选「是 / 全部替换」

解压后目录结构应为：

```
游戏目录/
├── BepInEx/                     # BepInEx 框架
│   ├── config/                  # 配置文件（含修改器存档 ModifierSettings.json）
│   ├── core/                    # 核心文件
│   ├── interop/                 # 首次启动游戏时自动生成，属正常现象
│   ├── plugins/                 # 插件目录
│   │   ├── ToolModBepInEx.dll   # 游戏插件（功能实现）
│   │   ├── ToolModData.dll      # 数据定义（两端共享的通信契约）
│   │   └── ...
│   └── ...
├── PVZRHTools/                  # 修改器界面
│   ├── PVZRHTools.exe           # 修改器主程序
│   ├── PVZRHTools.dll           # 界面与语言资源（务必一并保留）
│   ├── ToolModData.dll          # 数据定义（与 exe 同目录，不可缺）
│   ├── InitData.json            # 词条/植物/僵尸等静态数据
│   └── ...
├── doorstop_config.ini          # Doorstop 配置
├── winhttp.dll                  # Doorstop 代理（启动加载器）
├── .doorstop_version            # 启动加载器版本标记
├── PlantsVsZombiesRH.exe        # 游戏主程序
└── ...
```

> **三个易漏点**
> 1. `PVZRHTools\` 文件夹里的 `PVZRHTools.dll` 与 `ToolModData.dll` **必须存在**——只复制 exe 会打不开或界面异常。
> 2. `BepInEx\interop\` 首次启动游戏时才会生成，多等几秒属正常。
> 3. 修改器的语言 / 界面资源都在 dll 里，升级时 **exe 与 dll 要一起换**。

## 启动方式

1. **双击游戏本体** `PlantsVsZombiesRH.exe` 启动游戏
2. 游戏启动后，插件会自动拉起修改器窗口（无需手动运行）
3. 修改器会自动连接游戏，界面上方显示连接状态

> ⚠ **不要单独双击 `PVZRHTools\PVZRHTools.exe`**
> 单独启动会提示「修改窗口不允许单独启动」，这是**正常行为**，不是安装错误。

## 只想看界面？免游戏启动

如果你不打算开游戏、只想看看修改器界面（或调排版），可以用仓库里的
**`免游戏启动修改器.bat`**：

- 双击即可，**不需要启动游戏**
- 会弹出完整修改器窗口，所有页签都能正常浏览

**使用说明**

| 项 | 说明 |
|------|------|
| 换游戏目录 | 改脚本顶部的 `GAMEDIR` 一行即可 |
| 连接状态 | 会显示「未连接」；词条 / 植物等数据来自上次的 `InitData.json` |
| 功能是否生效 | **各类修改指令不会生效**（没有游戏可改），仅用于查看界面 |

原理：修改器需要两个启动参数 ——

```
PVZRHTools.exe  PVZRHTools  13531
                ↑ 令牌      ↑ 端口（与插件端一致）
```

并且**工作目录必须是游戏根目录**：启动 5 秒后它会读取
`.\PVZRHTools\InitData.json` 来填充词条/植物数据，工作目录不对就读不到。

## 语言设置

修改器支持三种语言：

- 简体中文
- English
- Русский（俄语）

在修改器界面右上角的下拉框中切换。

## 卸载

删除以下 5 项即可完全卸载：

- `BepInEx\`
- `PVZRHTools\`
- `winhttp.dll`
- `doorstop_config.ini`
- `.doorstop_version`

若你原本就装有 BepInEx（用于其它模组），则只删 `BepInEx\plugins\` 里的这两个文件：

- `ToolModBepInEx.dll`
- `ToolModData.dll`

## 环境要求

- 64 位 Windows 10 / 11
- **无需**安装 .NET、VC 运行库或任何其它软件（修改器自带全部运行环境）
- 仅依赖本压缩包 + 4.0 版本游戏本体

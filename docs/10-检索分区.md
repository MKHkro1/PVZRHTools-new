# PVZRHTools 检索分区

页签名：**检索分区**。用于**按 ID 或名称检索**游戏内的各类数据，以及**播放指定的特效与音效**。

这个页签是给"想确认某个 ID 到底是什么"的场景准备的 —— 例如：

- 阵容码里出现的数字编号，想知道对应哪个植物 / 僵尸
- 「锁定子弹类型」这类需要填 ID 的功能，先来这里查一下编号
- 想看看某个特效 / 音效编号长什么样

## 一、检索

顶部是搜索框，输入**中文或数字**都可以检索：

```
输入中文或数字进行检索...
```

### 结果分类

检索结果按类型分在 5 个可折叠区块里，各自独立列出：

| 区块 | 内容 |
|------|------|
| 植物 | 匹配到的植物及其 ID |
| 僵尸 | 匹配到的僵尸及其 ID |
| 词条 | 匹配到的词条（Buff）及其 ID |
| 子弹 | 匹配到的子弹类型及其 ID |
| 物品 | 匹配到的物品及其 ID |

- 每个区块都可以**单独折叠 / 展开**，只关心某一类时把其它折叠起来即可
- 没有匹配项的区块会显示「未找到匹配项」
- 输入数字时按 ID 匹配，输入中文时按名称匹配

## 二、特效和音效播放

页面下半部分是「特效和音效播放」区块，可以**直接在游戏里播放**指定的特效或音效。

| 项 | 说明 |
|------|------|
| 特效ID | 填入粒子特效编号 |
| 生成特效 | 按填写的编号在游戏中播放该特效 |
| 音效ID | 填入音效编号 |
| 生成音效 | 按填写的编号在游戏中播放该音效 |

### 使用方法

1. **先让游戏处于关卡内**（否则指令没有作用对象）
2. 在「特效ID」里填入编号
3. 点「生成特效」，特效会在游戏中播放出来

音效同理。

> 这两个功能纯粹是"看编号效果"用的 —— 想确认某个特效/音效编号是什么效果时很方便。
> 编号来源可参考游戏内数据或社区整理的编号表。

## 注意事项

- 检索是**本地**完成的：植物 / 僵尸 / 词条 / 子弹 / 物品的名称来自 `PVZRHTools\InitData.json`，
  不需要连接游戏也能搜索
- 「生成特效」「生成音效」需要**连接游戏**且在关卡内才会生效
- 部分编号可能对应不到任何资源，此时不会播放 —— 属于正常现象，换一个编号试试

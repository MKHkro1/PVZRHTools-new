# PVZRHTools 传送带与附加功能

本文档介绍几个分散在不同页面的附加功能：

- 传送带植物类型修改
- 自定义植物数值表
- 深渊作弊

> **关于花园修改器**：早期版本内置了 @听雨夜荷 的花园修改器（pvzRH-GardenEditor）。
> **该功能已在后续版本中移除**，当前版本界面里没有「花园修改器」按钮，本文档不再介绍。

---

## 一、传送带植物类型修改

### 功能说明

修改传送带关卡中出现的植物类型。

### 位置

「游戏内操作」页 →「布阵」分组底部。

### 使用方法

1. 勾选「传送带植物类型，重进关卡生效」
2. 在右侧的多选下拉框中勾选想要的植物（可多选）
3. **重新进入关卡**使修改生效

### 注意事项

- 修改后**需要重新进入关卡**才能生效 —— 局内改是没用的
- 清空列表将恢复默认传送带植物
- 该功能与原版传送带机制叠加，建议只选少量植物，避免传送带卡住

---

## 二、自定义植物数值表

### 功能说明

加载自定义的植物属性配置文件，批量修改植物的各项数值。

### 位置

「常用功能」页 / 「全局特性修改」页的「加载自定义植物数值表」按钮。

### 使用方法

1. 准备好植物数值配置文件
2. 点「加载自定义植物数值表」
3. 选择配置文件加载

### 注意事项

- **由于代码限制，无法保证所有条目均能生效**（原文说明）
- 部分硬编码在游戏内的数值可能无法修改
- 这是给进阶玩家批量调数值用的；只想改单项推荐用「数值修改」分组

---

## 三、深渊作弊

### 功能说明

深渊模式的作弊功能。

### 位置

「常用功能」页 →「深渊作弊」按钮。

### 使用方法

点击按钮即可。

> 另外「全局特性修改 → 其他特性」里还有一组**冒险秘境抽奖券**相关项
> （木券 / 银券 / 金券 / 钻石券 + 应用券数），用于写入各档位抽奖券数量，
> 属**写存档**操作，请谨慎填写。

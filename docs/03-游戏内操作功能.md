# PVZRHTools 游戏内操作功能

页签名：**游戏内操作**（左侧栏第 4 项）。含 3 个分组：

- **布阵** —— 生成植物/僵尸/物品、阵容码
- **游戏状态调整** —— 阳光金币、波次、清除、字幕等
- **僵尸海** —— 高频刷怪

另有一个独立页签 **斗蛐蛐布阵**（左侧栏第 9 项）。

---

# 一、布阵

> 页面说明：行、列号设为 0 表示整行/整列。

### 基本参数

| 参数 | 说明 |
|------|------|
| 行： | 目标行号，**设为 0 表示整行** |

# 二、游戏状态调整

### 资源

| 功能 | 说明 |
|------|------|
| 修改阳光 | 把阳光改为输入框中的数值<sup>※</sup> |
| 锁定阳光 | 阳光数量保持不变（持续维持） |
| 修改钱数 | 把钱数改为输入框中的数值（上限 99999）<sup>※</sup> |
| 锁定钱数 | 钱数保持不变（持续维持） |

> <sup>※</sup> **「修改」与「锁定」的区别**
> - **不勾锁定**点「修改」→ **改一次**，之后交回游戏正常增减
> - **勾了锁定**点「修改」→ 数值被**持续维持**在该值上
>
> 两者都真的会生效。若你只想改一次数值，直接点「修改阳光」即可，不必勾锁定。

### 波次

| 功能 | 说明 |
|------|------|
| 生成下一波僵尸 | 立即触发下一波僵尸 |
| 暂停出怪 | 暂停僵尸刷新 |
| 跳转指定波 | 把当前波次直接改为输入框中的数值（不超过最大波数） |
| 僵尸进家不死 | 僵尸进入房屋不会导致游戏失败（**勾选仅在本局生效**） |

### 无限刷新与积分

| 功能 | 说明 |
|------|------|
| 无限刷新和积分 | 一键开启下面两项 |
| 无限刷新 | 旅行商店 / 诸神进化无限刷新 |
| 无限积分 | 水果忍者无限积分 |

### 清除

| 功能 | 说明 |
|------|------|
| 清除全部植物 | 移除场上所有植物 |
| 秒杀全部僵尸 | 立即杀死场上所有僵尸 |
| 清除所有冰道 | 移除场上所有冰道 |
| 魅惑全部僵尸 | 将场上所有僵尸转为友方 |
| 清除所有坑洞 | 移除场上所有坑洞 |

### 小推车与奖杯

| 功能 | 说明 |
|------|------|
| 启动所有小推车 | 启动所有行的小推车 |
| 生成小推车 | 在指定行生成小推车（**不要点太快**） |
| 直接生成奖杯 | 直接生成过关奖杯 |
| 销毁场上奖杯 | 移除场上的奖杯 |

### 文字与关卡

| 功能 | 说明 |
|------|------|
| 修改关卡名称 | 修改当前关卡显示的名称 |
| 显示字幕 | 在游戏中显示自定义字幕 |

### 旗帜波词条（按 ID 顺序）

除了「旗帜波词条」页签外，这里还有一组**按 ID 顺序**配置的功能：

| 项 | 说明 |
|------|------|
| 旗帜波词条功能 | 总开关 |
| 旗帜波词条： | 选择词条 |
| 词条ID顺序： | 按 ID 顺序指定每面旗帜抽到的词条 |
| 按ID顺序应用 | 应用上面的配置 |

**词条ID顺序格式**

```
(a1,u2)()(d3,a0)
```

- **一对括号 = 一面旗帜**抽到的词条
- 上例：第 1 旗抽高级词条 1 和究极词条 2；第 2 旗不抽；第 3 旗抽负面词条 3 和高级词条 0
- 前缀字母：`a` = 高级词条、`u` = 究极词条、`d` = 负面词条
- **数字从 0 开始**

# 三、僵尸海

| 功能 | 说明 |
|------|------|
| 极限僵尸海 | 高频率生成大量僵尸 |
| 普通僵尸海 | 特性同原版 PVZ 僵尸海，每波 100 个怪，**需在进入关卡前开启** |
| 僵尸类型： | 选择僵尸海中出现的僵尸类型 |
| 生成间隔帧数： | 设置僵尸生成的间隔帧数 |

> ⚠ 僵尸海功能开销较大，可能造成卡顿。

---

# 四、斗蛐蛐布阵

独立页签（左侧栏第 9 项），相当于布阵的快捷版：一键铺好双方阵容，省去逐个生成。

---

## 注意事项

- **布阵相关功能都需要连接游戏且在关卡内**
- 行列号 **0 = 整行/整列**，这是最容易忘的一条
- 「阵容码格式」要选对：混合阵**仅支持高数型**格式
- 生成小推车不要连续快速点击
- 僵尸海请在**进入关卡前**开启

# PVZRHTools 我的面板

「我的面板」是一个**可自由排版的功能收藏页**：把你常用的功能挑出来放到一页，
省得每次切页签找。位于左侧栏第 2 个页签。

## 为什么它和原页面不会打架

面板里的功能**不是把原页面的控件搬过来**，而是"用同一份设置重新建一个控件"。

这意味着：

- 面板上勾了某个功能，**原页面里那个勾也会跟着变**（反之亦然）
- 原页面完全没改动，两边**状态始终一致**
- 不会出现"面板里改了但原页面没变"的情况

## 界面构成

| 区域 | 作用 |
|------|------|
| 添加功能 | 搜索框 + 候选下拉 + 「加入面板」按钮 |
| 面板内容 | 已加入的功能卡片，可上下移动、移除 |
| 面板列数 | 1 / 2 / 3 列，默认 2 列 |
| 配置存档 | 命名保存多套面板，随时切换 |

## 基本用法

### 添加功能

1. 在「添加功能」区输入关键词搜索（中文名或来源页名都可以）
2. 从下拉框选中目标功能
3. 点「加入面板」

> 下拉框只会列出**还没被加进面板**的功能。
> 若显示「已把全部可用功能都加入面板」，说明已经没有可加的了。

可选功能共 **262 项**，来自各个页面（常用功能、全局特性、游戏内操作、诸神进化……）。

### 调整顺序

每张功能卡片上带三个按钮：

| 按钮 | 作用 |
|------|------|
| 上移 | 与上一个功能交换位置 |
| 下移 | 与下一个功能交换位置 |
| 移除 | 从面板移除（不影响原页面的设置值） |

### 调整列数

用「列数」下拉框切换 **1 / 2 / 3 列**（默认 2 列）。

桌面端窗口较宽时用 2～3 列更紧凑；想看清长文案就用 1 列。

### 清空面板

点「清空面板」会移除全部卡片，**只清布局，不改任何功能开关的实际状态**。

## 多套配置存档

面板下方是「配置存档」区，可以把当前布局命名保存，方便在多套方案之间切换。

| 项 | 说明 |
|------|------|
| 配置名 | 输入一个名字 |
| 保存为新配置 | 保存当前布局（列数 + 卡片顺序） |
| 加载 | 把选中配置恢复到面板上 |
| 删除 | 删除选中配置 |

**说明**

- **当前面板的改动会自动保存**，重启修改器 / 游戏后自动恢复，不需要手动点保存
- 「保存为新配置」是给**多套方案**用的，例如「日常推图」「斗蛐蛐」「诸神进化」各存一套
- 若用同一个名字再次保存，会**覆盖更新**那一套
- 加载某套配置时，面板会被替换成该套的内容（未知/失效的功能项会被跳过）

## 注意事项

- 面板布局是**独立保存**的，与你是否勾选「关闭时保存现有设置」无关 ——
  布局永远自动保存，不会被那个开关影响
- 「移除」只影响面板显示，**不会把功能关掉**；要关功能请直接点卡片上的勾选框
- 若某个功能项在面板里显示不出来（例如依赖的候选列表来自游戏数据），
  请回到原页面使用 —— 少数依赖游戏动态数据的多类型下拉项目前不支持加入面板

# PVZRHTools 词条专区与旗帜波词条

本文档介绍两个与"词条（Buff）"相关的页签：

- **词条专区**（左侧栏第 10 项）：针对特定玩法的词条套装
- **旗帜波词条**（左侧栏第 11 项）：按"第几旗"分别配置词条 + 字幕

> 通用词条设置（初始词条 / 实时词条）在「旅行词条修改」页，见
> [05-旅行词条与快捷键](05-旅行词条与快捷键.md)。

## 一、词条专区

页签名：**词条专区**。这里放的是"成套的词条组合"，勾一下就给对应目标加上一组词条。

页面分两块：

| 区块 | 作用对象 |
|------|----------|
| 植物词条 | 给植物加词条 |
| 僵尸词条 | 给僵尸加词条 |

### 植物词条

| 词条 | 说明 |
|------|------|
| 坚不可摧（鱼丸限伤200） + 高级后勤（双倍恢复，阳光磁力菇CD减少） | 坚不可摧：鱼丸受到的伤害最多为 200<br>高级后勤：鱼丸恢复血量时恢复双倍血量，阳光磁力菇冷却时间大幅减少 |

> 该区块另有「僵尸词条功能待添加」的占位说明 —— 即僵尸词条区块目前**尚在开发中**，
> 界面上会显示占位文案，属正常现象。

## 二、旗帜波词条

页签名：**旗帜波词条**。用于给**每一面旗帜波**单独配置一套词条，并可显示自定义字幕。

这是"按旗帜波投放词条"的功能：第 1 旗一套、第 2 旗另一套……

### 界面构成

| 区域 | 说明 |
|------|------|
| 词条选择 | 总开关 |
| 自定义字幕 | 每面旗帜可各写一行字幕 |
| 第 1 旗 ~ 第 10 旗 | 各自一个「词条选择」多选框 + 一个「自定义字幕」输入框 |

### 使用方法

1. 勾选顶部的「词条选择」总开关，启用本功能
2. 展开对应的「第 N 旗」，点开多选框**勾选**该旗要生效的词条（可多选）
3. 如需在该波显示字幕，在对应的「自定义字幕」输入框里填文字
4. 进入关卡，到达该旗帜波时词条与字幕自动生效

### 注意事项

- 每面旗帜可勾选**多个**词条（勾选框为多选）
- 词条在多选框里可以搜索过滤 —— 文件量大时用搜索更快
- 字幕留空表示该旗不显示字幕
- 旗帜波编号对应游戏内的第 1/2/3… 面旗，与"第几波"不是同一个概念

## 三、和「旅行词条修改」页的区别

容易混淆，特此说明：

| 页签 | 生效方式 | 适用场景 |
|------|----------|----------|
| 旅行词条修改 | 一次性全部应用（开局 / 实时） | 想让整局都带某套词条 |
| 旗帜波词条 | 按**第几面旗**分别投放 | 想让不同阶段出现不同词条 |
| 词条专区 | 成套的组合词条 | 一键给某类目标加一组特定词条 |

三个页签互不冲突，可以同时使用。

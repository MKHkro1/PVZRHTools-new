# PVZRHTools 快捷键名称对照表

「游戏内按键绑定」页的按键是**从下拉列表里选的**，列表里显示的是英文名称
（例如 `Alpha9`、`Colon`、`Semicolon`），很多人不知道它们对应键盘上哪个键。

本文档把这份列表**按键盘上的物理位置**整理一遍，照着键盘找即可。

> **只适用于「游戏内按键绑定」页**（单键下拉框）。
> 「全局按键绑定」页是直接按键盘录入的，不显示这些英文名，详见
> [05-旅行词条与快捷键](05-旅行词条与快捷键.md)。

---

## ⚠️ 先看这两条，最容易搞错

| 事项 | 说明 |
|------|------|
| **`Alpha0` ~ `Alpha9` 是主键盘的数字键** | `Alpha9` = 键盘上**那一排**的 `9` 键，**不是小键盘的 9** |
| 小键盘的 9 叫 **`Keypad9`** | 小键盘（NumPad）那一整块都是 `Keypad*` 开头，共 17 个 |

另外，这些英文名用的是**美式键盘**的符号命名。
中文输入法 / 其它布局下选不奏效时，以**物理按键位置**为准。

---

| 物理键位 | 直接按 | 加 Shift | 备注 |
|----------|--------|----------|------|
| `` ` `` | `BackQuote` | `Tilde` | **` 键**（1 键左边那个） |
| `1` | `Alpha1` | `Exclaim` | `!` |
| `2` | `Alpha2` | `At` | `@` |
| `3` | `Alpha3` | `Hash` | `#` |
| `4` | `Alpha4` | `Dollar` | `$` |
| `5` | `Alpha5` | `Percent` | `%` |
| `6` | `Alpha6` | `Caret` | `^` |
| `7` | `Alpha7` | `Ampersand` | `&` |
| `8` | `Alpha8` | `Asterisk` | `*` |
| `9` | `Alpha9` | `LeftParen` | `(` |
| `0` | `Alpha0` | `RightParen` | `)` |
| `-` | `Minus` | `Underscore` | `-` / `_` |
| `=` | `Equals` | `Plus` | `=` / `+` |

## 二、字母区（26 个）

**直接就是字母本身**，名称为大写字母：

| 行 | 名称 |
|----|------|
| Q 排 | `Q` `W` `E` `R` `T` `Y` `U` `I` `O` `P` |
| A 排 | `A` `S` `D` `F` `G` `H` `J` `K` `L` |
| Z 排 | `Z` `X` `C` `V` `B` `N` `M` |

## 三、符号键（字母区右侧 / 下方）

| 物理键位 | 直接按 | 加 Shift | 备注 |
|----------|--------|----------|------|
| `[` | `LeftBracket` | `LeftCurlyBracket` | `[` / `{` |
| `]` | `RightBracket` | `RightCurlyBracket` | `]` / `}` |
| `\` | `Backslash` | `Pipe` | 反斜杠 / `\|` |
| `;` | `Semicolon` | `Colon` | **分号 `;` / 冒号 `:`** |
| `'` | `Quote` | `DoubleQuote` | 单引号 / 双引号 |
| `,` | `Comma` | `Less` | `,` / `<` |
| `.` | `Period` | `Greater` | `.` / `>` |
| `/` | `Slash` | `Question` | `/` / `?` |

> 你截图里看到的 `Colon`、`Semicolon`、`Less`、`Equals`、`Greater`、
> `Question`、`At`、`LeftBracket`、`Backslash`、`RightBracket`
> 全部在这一张表里。

## 四、小键盘（NumPad）

**小键盘的数字是 `Keypad*`，和主键盘的 `Alpha*` 是两回事。**

| 物理键位 | 名称 |
|----------|------|
| 0 ~ 9 | `Keypad0` ~ `Keypad9` |
| `.` | `KeypadPeriod` |
| `/` | `KeypadDivide` |
| `*` | `KeypadMultiply` |
| `-` | `KeypadMinus` |
| `+` | `KeypadPlus` |
| Enter | `KeypadEnter` |
| `=` | `KeypadEquals` |

> 小键盘区域在不少笔记本上会被省略；**游戏内是否能用取决于键盘是否有该物理键**。

## 七、修饰键（Shift / Ctrl / Alt 等）

| 名称 | 物理键 |
|------|--------|
| `LeftShift` / `RightShift` | 左右 Shift |
| `LeftControl` / `RightControl` | 左右 Ctrl |
| `LeftAlt` / `RightAlt` | 左右 Alt |
| `LeftCommand` / `RightCommand` | ⌘ 键（Mac） |
| `LeftWindows` / `RightWindows` | Windows 徽标键 |

> 「游戏内按键绑定」是**单键**绑定，选 `LeftShift` / `LeftControl` 这类修饰键时，
> 游戏里按下它是否会单独触发，取决于游戏是否支持纯修饰键热键。

## 八、鼠标键

| 名称 | 说明 |
|------|------|
| `Mouse0` ~ `Mouse6` | 鼠标按键编号（0 通常为左键、1 中键、2 右键） |

> ⚠ 鼠标键是否可用取决于游戏是否支持鼠标热键；实测多数情况下**不可用**，
> 建议优先用键盘键位。

## 九、特殊情况：`None`

| 名称 | 说明 |
|------|------|
| `None` | **不设置快捷键**（列表第一项） |

---

## 附：怎么快速确认某个英文名是哪个键

按下图所示位置对照即可；实在拿不准时，最稳妥的办法是：

1. 先在「全局按键绑定」页把该功能绑一个**组合键**并试一下
2. 或在「检索分区」页用文字确认

> 但请注意：**全局按键与游戏内按键是两套独立配置**，
> 全局能用的键不一定能用于游戏内，反之亦然。

## 快速开始

1. 下载修改器：<https://pan.quark.cn/s/958659c83f52>
2. 把压缩包内**全部内容**解压到游戏 exe 所在文件夹（覆盖提示选「全部替换」）
3. **直接双击游戏本体启动** —— 游戏启动后会自动打开修改器窗口

> 修改器**不支持单独双击启动**。想只看界面不开游戏，用
> [01-安装与启动说明](01-安装与启动说明.md) 里给的「免游戏启动修改器.bat」。

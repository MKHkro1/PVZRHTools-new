# PVZRHTools 出怪修改

页签名：**出怪修改**（左侧栏第 13 项）。用于**查看当前波数**并**逐条修改各波次的出怪列表**。

> 这是"改某波出什么僵尸"的功能 —— 例如想把第 3 波的铁桶换掉，就用这个页面。

## 界面构成

| 区域 | 作用 |
|------|------|
| 当前波数 | 显示当前进行到第几波 |
| 获取列表 / 刷新 | 拉取当前关卡的出怪配置 |
| 出怪列表 | 按波次展开的僵尸编辑区 |

## 使用方法

### 1. 获取出怪列表

1. **先进入关卡**（本页需要读取关卡数据）
2. 点右上角的刷新按钮获取列表
3. 「当前波数」会显示为「第 N 波」；若还没读到会显示「未获取」

### 2. 修改某一波的出怪

列表按**波次**分组，每波是一个可折叠区块：

```
出怪列表 (N 个)          ← 该波僵尸条目数，点标题展开/收起
  [0]  <僵尸类型下拉框>  [应用]
  [1]  <僵尸类型下拉框>  [应用]
  ...
```

- **当前所在波次会自动展开**，其它波次默认收起
- 每一行代表该波的一个出怪条目，`[n]` 是条目序号
- 在下拉框里选新的僵尸类型，然后点该行的「应用」按钮，修改才会写入
- 下拉框展示的是**僵尸中文名**，实际写入的是对应 ID

### 3. 修改后生效时机

修改写入的是关卡当前的出怪配置。已经出现过的僵尸不会变化，
**后续生成**的僵尸会按修改后的配置出现。

## 注意事项

- **必须连接游戏且在关卡内**：不在关卡里点刷新会读不到数据，显示「未获取」
- 修改是**逐条应用**的 —— 改完下拉框一定要点「应用」，只选不点不会生效
- 如果该波没有数据，会显示「无数据」提示
- 「当前波数」只在进入关卡后才有意义；回到主菜单后可能需要重新获取
- 这是**局内**修改，换关后会重新读取该关卡自己的出怪配置（不会带到下一关）

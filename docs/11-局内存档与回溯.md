# PVZRHTools 局内存档与回溯

页签名：**局内存档/回溯**。用于在关卡内**保存现场快照**，之后随时**恢复**回去。

适用场景：手滑清场了、试阵容想反悔、想回到某个关键局面重来。

## 界面构成

这个页面很简洁，只有三个按钮加一块信息显示区：

| 按钮 | 作用 |
|------|------|
| 立即保存快照 | 把当前局面存成快照 |
| 恢复最近快照 | 回到最近一次保存的快照 |
| 刷新快照信息 | 重新读取并显示当前快照的内容摘要 |

下方「当前快照信息」区会显示最近快照的详细内容。

## 保存快照

点「立即保存快照」即可。

**如果关卡还在初始化**，修改器不会立刻失败，而是：

- 游戏内提示「正在初始化，稍后保存快照…」
- 自动等待关卡就绪（最多约 3 秒）后再保存
- 保存成功时提示「已保存快照」
- 真的等超时了才提示「当前关卡尚未初始化完成，快照失败」

所以刚进关卡时点保存也能正常用，不用刻意等。

## 恢复快照

点「恢复最近快照」会**回滚到最近一次保存的局面**。

恢复的内容包括：

| 内容 | 说明 |
|------|------|
| 词条 | 高级 / 终极 / 负面 / 投资词条的状态 |
| 植物 | 场上植物（位置 + 类型） |
| 僵尸 | 场上僵尸（位置 + 类型 + 血量） |
| 罐子 / 格子物品 | 场上的罐子与掉落物 |
| 关卡标记 | 种子雨、纵列种植、胆小菇之梦 |
| 阳光 / 金币 | 当时的数值 |
| 卡槽 | 手牌与冷却状态 |

恢复时会先清空当前场上的植物、僵尸与罐子，再按快照重建，**不是"叠加"而是"覆盖"**。

> 恢复会**重置当前局面**，请确认清楚再点。

## 快照信息区

点「刷新快照信息」可以查看最近快照的内容摘要，包括：

- 捕获时间
- 关卡类型 / 关卡编号 / 生存轮次
- 波次进度（第几波 / 共几波）、是否巨大波
- 距下一波时间、波间隔
- 阳光 / 金币
- 关卡标记（种子雨 / 列种 / 胆小菇梦境）
- 各类词条数量
- 格子物品数 / 罐子数
- 卡槽数 / 卡片冷却 / 掉落物冷却
- 植物血量 / 僵尸血量条目数
- 随机种子

若还没有任何快照，会显示「暂无快照文件」。

## 关于自动快照

界面上**没有**自动快照相关选项 —— 自动快照与跨会话自动恢复功能已经移除，
目前版本只保留**手动保存 / 恢复**。

> 语言资源文件里仍留有 `启用自动快照`、`秒` 这两个旧文案键，但界面上没有对应控件，
> 属于历史残留，无实际功能，可以忽略。

## 快照文件位置

快照会同时保存在内存中，并落盘到：

```
游戏目录\PVZRHTools\Snapshots\LatestSnapshot.json
```

- 内存中保留最近若干个快照（环形缓冲），恢复时优先用内存里的
- 若内存缓冲为空（例如**重启过游戏**），会自动回退读取磁盘上的最近快照
  —— 所以**重启游戏后仍可恢复到上次保存的局面**

删除该文件即可清掉磁盘上的快照记录。

## 注意事项

- 快照保存的是**当前关卡**的局面，换关后不会自动带过去
- 需要**连接游戏**且在关卡内才能使用
- 恢复是整体覆盖，会清掉当前场上的植物与僵尸
- 快照信息区的血量/词条等条目数只是**计数**，用来快速判断快照完整性

# PVZRHTools 常见问题与注意事项

## 常见问题

### Q: 修改器打不开 / 提示「修改窗口不允许单独启动」？

A: 这是**正常行为**。修改器不支持单独启动，必须由游戏拉起：

1. **直接双击游戏本体** `PlantsVsZombiesRH.exe`
2. 游戏启动后会自动打开修改器窗口

若确实想只看界面不开游戏，用 [01-安装与启动说明](01-安装与启动说明.md) 里的
「免游戏启动修改器.bat」（注意：那种模式下修改指令不会生效）。

### Q: 修改器无法连接游戏？

A: 请依次确认：

1. **是双击游戏本体启动的**（不是单独开修改器）
2. `BepInEx\plugins\` 下有 `ToolModBepInEx.dll` 与 `ToolModData.dll`
3. `PVZRHTools\` 下有 `PVZRHTools.exe`、`PVZRHTools.dll`、`ToolModData.dll`
4. 游戏版本与修改器匹配（当前适配 **4.0**）
5. 首次启动游戏时 `BepInEx\interop\` 需要生成，多等几秒

> 若装过多个修改器（例如同时装了旧版本），可能出现"连接上了但功能互相覆盖"，
> 建议只保留一套。

### Q: 某些功能不生效？

A: 常见原因：

1. **该功能需要在进入关卡前开启**（如关卡特性附加、僵尸海、传送带植物类型）
2. **需要连接游戏且在关卡内**（如布阵、清除、快照）
3. **数值项需要先勾选左侧启用框**再填值（尤其「诸神进化」页 —— 不勾选 = 沿用游戏默认值）
4. 需要**先点「应用」按钮**（如出怪修改的每一行）
5. 该功能只在特定关卡类型 / 模式下有效
6. 游戏版本更新可能导致个别功能失效

> 排查技巧：先用该功能的**快捷键**（若绑定了）触发一次，看有没有反应，
> 以区分"按钮没点到"和"功能本身不生效"。

### Q: 点了「修改阳光」没反应？

A: 请确认：

1. **已连接游戏且处于关卡内**（否则点多少次都不会生效）
2. 看的不是「锁定阳光」那个勾选框

**「修改阳光」与「锁定阳光」的区别**：

| 操作 | 效果 |
|------|------|
| 只点「修改阳光」 | **改一次**，之后交回游戏正常增减 |
| 勾「锁定阳光」再点「修改阳光」 | 数值被**持续维持**在该值 |

两者都真的会生效，按需要选一种即可。「修改钱数」同理。

### Q: 游戏崩溃了怎么办？

A: 依次尝试：

1. 重启游戏和修改器
2. 关闭可能冲突的功能（**逐个关掉排查**）
3. 避免使用已声明不稳定的功能（锁定子弹类型、随机卡槽等）
4. 确认没有同时装两套修改器

### Q: 阵容码无法导入？

A: 请检查：

1. 阵容码格式是否正确
2. 「阵容码格式」选择是否匹配（**混合阵仅支持高数型**）
3. 数组规模是否过大 —— 僵尸数量超过 2000 会导致崩溃

### Q: 快捷键不生效？

A: 请确保：

1. 切换为**英文输入法**（按键绑定控件来自 FastHotKeyForWPF，必须英文输入法）
2. 全局按键用**组合键**而非单键（游戏内按键才支持单键）
3. 游戏窗口处于激活状态
4. 全局按键在游戏运行时**会占用该键位**，其它软件中会失效

### Q: 重启游戏后修改器设置还在吗？

A: 分情况：

| 内容 | 是否自动保存 |
|------|--------------|
| 「我的面板」布局 | **始终自动保存**（独立持久化，不受开关影响） |
| 一般功能开关 | 取决于「关闭时保存现有设置」是否勾选 |
| **数值修改** | **不保存**（该开关明确排除） |
| **游戏内词条修改** | **不保存**（同上） |
| 局内快照 | 保存到 `PVZRHTools\Snapshots\`，重启后仍可恢复 |

### Q: 「诸神进化」页的数值填了没用？

A: 该页的**数值类选项必须先把左侧的小方框勾上**才会覆盖游戏默认值；
不勾选 = 沿用游戏默认值。另外本页只对「**诸神：进化**」模式生效。
改完记得点「立即应用到局内」。

## 已知问题

### 卡槽替换（已移除）

早期版本的「卡槽替换」页签**已从界面移除**。

原文说明：

> 此修改由于无法修复的 bug 过多，暂时将就着玩吧，仅供娱乐，重启游戏可能会解决问题

需要换卡槽植物可用「随机卡槽」代替。

### 锁定子弹类型

- 可能引发各种奇怪的 bug
- 仅供娱乐，不会做针对性修复

### 僵尸海

- 开销较大，可能导致卡顿
- 「普通僵尸海」需在**进入关卡前**开启

### 关卡特性附加

- 排山倒海、种子雨、诸神系列、胆小菇之梦等
- 可能与其他功能存在兼容冲突
- 请在进入关卡前开启

### 花园修改器（已移除）

早期版本内置的花园修改器**已在后续版本中删除**，界面里已无该入口。

### 界面残留说明

语言资源文件里仍保留若干**旧文案键**，但界面上**没有对应控件**，属历史残留、无实际功能，可忽略。

已核实的残留键（**界面上找不到这些选项是正常的**）：

| 残留在哪个分组 | 残留项 |
|----------------|--------|
| 关卡特性附加 | 等价交换、诸神1、诸神2、诸神3、诸神：全军出击 |
| 场地特性 | 巨人扔出的僵尸类型、舞王撑杆召唤僵尸类型 |
| 僵尸特性 | 僵尸免疫一切负面效果（总开关）—— 实际可用的是 9 个逐项免疫勾选框 |
| 其他特性 | 水果忍者无限积分、诸神进化无限刷新、旅行随机无限刷新<br>（实际控件在「游戏内操作」页：「无限刷新」「无限积分」） |
| 数值修改 | 植物初始血量修改 —— 该分组实际只有僵尸血量 / 一类防具 / 二类防具 / 子弹伤害 |
| 局内存档/回溯 | 启用自动快照、秒 |
| 卡槽替换（整页已移除） | 该页全部条目 |

> 看到这些名字在别处被提到（例如旧截图、旧教程），说明那份资料对应的是**早期版本**。

## 注意事项

### 安全提示

- 本修改器完全免费且已在 GitHub 开源
- 若遇到付费 / 要求三连+关注 / 私信发链接的情况，说明你被骗了
- 请注意隐私和财产安全

### 使用建议

1. 建议在**单机模式**下使用修改器
2. **使用前备份存档**（尤其涉及「写存档」的功能，如诸神币、抽奖券）
3. 不稳定功能请谨慎使用
4. 遇到问题先尝试重启游戏
5. 一次只开一个功能，出问题时好定位

### 性能注意

- 植物攻击无间隔、植物无敌等高频功能可能影响性能
- 「窝红温了」等叠植物类功能，**植物叠太多会导致问题**
- 僵尸海、极限僵尸海会大幅增加实体数量，可能卡顿

### 多人 / 联机

修改器仅供**单机**使用，请勿在联机环境使用。
